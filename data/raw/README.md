# `data/raw/` — the source data drop (not redistributed)

Everything in this directory except this file is **gitignored and absent from a
fresh clone**. The drop is 143 files and 98.0 MB of third-party material: a
climate-model discharge ensemble supplied under a research collaboration, agency
survey and rating tables, borehole logs from a national database, and national
elevation tiles. None of it is the author's to relicense, so the repository
publishes the *derived* products and the code that derives them, and documents
the inputs here precisely enough that a holder of the same data can verify they
have the right drop.

**What *is* published**, and is enough to read every result without this
directory:

* `data/processed/` — the geotechnical source of truth, the 2016 event extract,
  and the Uemura Phase 3 segment and surface-curve tables (all derived here);
* `docs/decisions/*.json` — the measured evidence behind every ADR and study;
* `docs/figures/` — the 71 publication figures;
* `docs/tokachi_bep_inputs_provenance.md` — a per-cell audit trail from raw
  source to the model input CSV.

What needs this directory is **re-running** Phase 1 sweeps or the Phase 3
composition from scratch.

## 1. Required layout

Scripts resolve paths beneath `data/raw/` by name; the layout is part of the
contract, not a convenience.

```
data/raw/
├── hydrographs/                 d4PDF discharge ensembles, 6 workbooks   (ADR-0019, ADR-0020)
├── rating_curves/               H-Q coefficients, 2 CSV                  (ADR-0019 §5)
├── bank_heights/                2019 design bank heights, 4 CSV          (ADR-0018)
├── geometry/                    HWL tables + DEM tiles and profiles      (ADR-0018, ADR-0047)
│   ├── BankHeight_*Riv_2019.csv
│   ├── FG-GML-644331-DEM5A-20250620/   100 JPGIS(GML) tiles
│   └── dem_cross_sections/             generated by the DEM driver
├── gis/                         SECTIONS.shp + target_area.shp           (ADR-0043, ADR-0047)
├── borehole_and_soil_survey/    5 Kunijiban logs + transcriptions        (ADR-0048)
├── overflow_provenance/         2016 LP survey behind the bank heights   (ADR-0042)
├── Uncertainty_HQrelation.xlsx  rating-error statistics                  (ADR-0042 decision 6)
└── Adobe Scan Jul 21, 2026.pdf  scanned gauge tables
```

`geometry/dem_cross_sections/` and its `_mosaic_cache.npz` are **generated**, not
supplied: `scripts/dem_cross_section_study.py` writes them from the DEM tiles
alone. Delete them and they are rebuilt.

## 2. Provenance, per source

| Source | Origin | Notes |
|---|---|---|
| `hydrographs/*.xlsx` | d4PDF discharge ensemble, supplied by K. Uemura (Docon) via the project data share, July 2026 | One sheet `QT` per file; column 1 `Time` = integer hours 1..192; each further column is one ensemble member's Q(t) in m³/s. Split by river and **KP band**, with the band in the filename; the band is parsed, never hard-coded (ADR-0020 decision 4). `HPB` = historical, `HFB` = +4 K. |
| `rating_curves/HQrelation_*Riv_2017.csv` | Hokkaido Regional Development Bureau, Obihiro Development and Construction Department | **Shift-JIS encoded, not UTF-8**, and the `HQ_a`/`HQ_b` header cells contain full-width characters — the loader specifies the encoding explicitly. Coefficients at 0.2 km spacing; coverage exceeds the study reach. |
| `bank_heights/`, `geometry/BankHeight_*Riv_2019.csv` | Official 2019 design bank-height tables | Columns `River, KP, HWL, DesignBankHeight_L, DesignBankHeight_R` at 0.2 km spacing, on the MSL datum — the same datum as the rating-curve stage output, which is what makes them the correct HWL source (ADR-0018). The two `DesignBankHeight_*` columns belong to the Phase 3 overflow mechanism, not to Phase 1. |
| `geometry/FG-GML-644331-DEM5A-20250620/` | Geospatial Information Authority of Japan (GSI), Fundamental Geospatial Data DEM5A, 2025-06-20 vintage | 100 JPGIS(GML) `.xml` tiles, 5 m posts. **Openly available** from the GSI download service under the Basic Act on the Advancement of Utilizing Geospatial Information; re-downloadable by tile id. QGIS cannot open these natively — the repository parses them directly (ADR-0047). |
| `gis/SECTIONS.*` | The very shapefile used by Uemura's WP2 notebook | 9 named polylines, JGD2000 Plane CS XIII (EPSG:2455). Secured 2026-07-02. Drives the Phase 3 segment-to-section assignment (ADR-0043) and the DEM profile alignment (ADR-0047). |
| `borehole_and_soil_survey/*.pdf` | 国土地盤情報検索サイト (Kunijiban / PWRI) borehole logs | 5 scanned logs, no text layer; rasterised at 200 dpi and transcribed by hand into `TRANSCRIPTION_layers.csv` and `TRANSCRIPTION_tests.csv`. Per-log campaign, client, contractor and Kunijiban XML ids are in `SOURCE_METADATA.md` beside them. Re-retrievable from Kunijiban by viewer id. |
| `overflow_provenance/BH_LPdata_*Riv_2016.csv` | 2016 longitudinal-profile survey | The measurement behind the averaged bank-height tables; retained so the averaging is auditable. |
| `Uncertainty_HQrelation.xlsx` | Uemura, rating-error statistics | The source of the H-Q rating-error terms adopted in ADR-0042 decision 6 (Tokachi ← Obihiro −0.160 / 0.294; Satsunai ← Nantai −0.051 / 0.283). |

## 4. Regenerating the manifest

```powershell
python - <<'PY'
import hashlib, pathlib
root = pathlib.Path("data/raw")
for p in sorted(root.rglob("*")):
    if p.is_file() and p.name != ".gitkeep":
        h = hashlib.sha256(p.read_bytes()).hexdigest()
        print(f"{h}  {p.relative_to(root).as_posix()}")
PY
```

## 5. If you do not have the drop

The test suite passes without it. Tests run on synthetic and committed fixtures
throughout; the few that can also exercise this directory — the DEM
cross-section study and the foreshore-exhaustion screening — are guarded and
skip when it is absent, and nothing here is asserted on. Scripts behave the same
way. The published figures, evidence JSONs and reports carry the results
themselves.

To obtain it: the DEM tiles are open (GSI download service, by tile id); the
Kunijiban borehole logs are open (viewer ids in `SOURCE_METADATA.md`); the
discharge ensemble, rating curves, bank-height tables and section shapefile were
provided for this project and should be requested from their originators, named
in section 2 above.
